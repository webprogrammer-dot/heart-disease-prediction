# Heart Disease Prediction

This project was done during my B.Tech as part of exploring machine learning in healthcare. The idea was to predict whether a person is likely to have heart disease based on some medical attributes.

## What I did
- Worked with a dataset containing features like age, cholesterol, blood pressure, etc.
- Cleaned the data and handled missing values
- Tried different models like Logistic Regression, Decision Tree and Random Forest
- Compared their performance and selected the best one

## Challenges
One issue I faced was that the data was not perfectly balanced, so the model could get biased. I tried to improve results using preprocessing and better feature selection.

## Result
The models were able to give decent prediction accuracy, and Random Forest performed better compared to others (from my experiments).
